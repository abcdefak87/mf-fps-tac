Breach Protocol — a round-based tactical FPS in three.js: breach-and-plant rounds, buy-menu economy, recoil and headshot gunplay, squad bots on nav routes, an original map, and a deterministic dossier.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click Play, buy a rifle, plant the spike.
